
# 🌊 Marine-Log  
### 해양 환경 정화 활동을 위한 통합 ICT 플랫폼  
*2025년 제 15회 ICTCoC 피우다 프로젝트 과제물*  

---

## 📘 프로젝트 개요  

**Marine-Log**는 전국 해양 정화 단체들의 활동 데이터를 표준화하여  
활동 기록, 시각화, 분석, 보고서 자동 생성을 지원하는 통합 ICT 플랫폼입니다.  

기존의 수기 기록과 비표준 데이터로 인한 문제(성과 집계의 어려움, 행정 부담, 중복 활동 등)를  
데이터 기반 관리 및 자동화 시스템을 통해 해결합니다.  

---

## 🎯 개발 목표  

- 해양 정화 활동 데이터의 **표준화 및 중앙 통합 관리**
- 활동별 **정량/정성 데이터 구조화**
- **지도 기반 시각화**로 중복 방지 및 소외 지역 발굴
- **보고서 자동 생성**을 통한 행정 효율화
- **단체 간 정보 공유 및 협업 활성화**

---

## 🧩 주요 기능  

### 1. 활동 생성 및 현장 데이터 수집  
> 데이터 수집은 활동 책임자만 수행  

1. 활동 책임자(단체장, 부단체장, 간부, 또는 권한 위임자)가 **스마트폰 앱 로그인 시 당일 활동**이 표시됨.  
2. **[시작]** 버튼을 누르면 활동 시작 시간이 자동 기록.  
3. **폐기물 분석용 사진 업로드**  
   - 폐기물을 겹치지 않게 분산 후 여러 장으로 촬영 및 업로드.  
4. **활동 현장 사진 촬영 및 등록.**  
5. **[종료]** 버튼 클릭 시 종료 시간이 기록되고 모든 데이터가 서버로 전송.  
   - 네트워크 불안정 시 오프라인 캐시로 임시 저장 → 연결 복구 시 자동 동기화.  
6. **활동 종료 예상 시간 기준 3시간 경과 시 미완 알림.**  
   - 미완 활동은 앱 푸시 알림으로 리마인드됨.  
   - 웹앱에서 누락된 데이터를 직접 입력 및 보완 가능.  

---

### 2. 서버 분석 및 저장  

1. 앱을 통해 업로드된 **폐기물 이미지, 활동 시간, 수기 데이터**가 서버에 저장.  
2. AI 모델이 폐기물 사진을 분석하여 **재질 및 품목 자동 분류.**  
3. 분류 결과를 기반으로 **정량적 성과 데이터 자동 생성.**  

---

### 3. 통합 웹 대시보드  

1. **히트맵**을 통해 정화 활동이 집중된 지역과 소외된 지역을 한눈에 확인.  
2. **기간별 / 지역별 / 단체별 성과 그래프**로 시각화된 통계 제공.  

---

### 4. 자동 보고서 생성  

1. 주요 성과와 시각 자료를 포함한 **PDF 요약 보고서 자동 생성.**  
2. **월간 / 분기 / 연간 보고서** 등 다양한 기간 단위로 출력 지원.  

---

### 5. 유사 활동 제안 및 활동 추천  

1. 사용자 만족도(5점 척도)를 기반으로 **유사 활동 추천.**  
2. **활동 후기 공유 게시판**을 통해 단체 간 교류 및 협업 유도.

## 🗺️ 기대 효과  

- **데이터 기반 활동 관리:**  
  표준화된 기록으로 지속 가능한 데이터 자산 구축.  
- **행정 효율성 향상:**  
  자동 보고 및 통계화로 활동가의 업무 부담 절감.  
- **활동 전략 최적화:**  
  시각화 기반으로 중복 방지 및 협업 촉진.  
- **대외 설득력 강화:**  
  수치 기반 보고서로 후원 및 공공기관 대응력 향상.  
- **공공 데이터 보완:**  
  정부 사업 중단 이후 민간 차원의 해양 환경 데이터 체계 구축.
